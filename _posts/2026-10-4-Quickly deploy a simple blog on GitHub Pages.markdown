# How to Create Your Own Blog

## 1. Fork the Repository

Fork the repository below and name the fork using your GitHub account name:

https://github.com/Huxpro/huxpro.github.io

## 2. Modify Site Information

Edit the `_config.yml` file to configure your site information.

## 3. Edit Your Blog

Add or edit Markdown files in the `_posts` directory.

Make sure the beginning of each post file follows the format below:

```yaml
---
layout:     post
title:      "Title"
subtitle:   "Subtitle"
date:       2026-10-04 12:00:00
author:     "Author"
header-img: "img/post-bg-2015.jpg"
catalog: true
tags:
    - Github Pages
---

Write your blog content here.
```

The content of your blog post goes below the front matter.
